I used the IPstack API to get location information based on an IP address. It returns JSON data including country, region, city, latitude, longitude, and timezone. I selected it because it is simple to access with GET requests and provides user-friendly data.

Website: https://ipstack.com

API parameters used:IP address or check to detect current IP and acess key.

Use case: This API can be used for personalizing content for users based on their location or for building geolocation-based applications.
