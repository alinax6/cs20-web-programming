I used the ipapi API to get location information based on an IP address. It returns JSON data including country, region, city, latitude, longitude, and timezone. I selected it because it is simple to access with GET requests and provides a lot data based on the ip address.

Website: https://ipapi.co/

API parameters used: I used the IP address (8.8.8.8) in the query string. The API requires an IP address in order to return the geographic information based on the address.

Use case: This API can be used for websites that want to personalize content based on a user's location, like showing currency, language preferences, or targeted advertising.
